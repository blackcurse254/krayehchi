# کرایه‌چی

وب‌اپ (PWA) پرداخت سریع کرایه تاکسی با QR و کارت‌به‌کارت. بدون بک‌اند و بدون واسطه مالی؛ اطلاعات راننده داخل لینک/QR کدگذاری می‌شود.

> ⚠️ صفحه «پرداخت» و رسید برای مسافر **تأیید بانکی نیست**. راننده باید پیامک بانک را بررسی کند و مسافر نام گیرنده در اپ بانک را با نام راننده و پلاک مقایسه کند.

## اجرا
```bash
npm install
npm run dev      # توسعه
npm test         # تست‌ها
npm run build    # خروجی در dist/
```

## انتشار رایگان

**GitHub Pages** (خودکار): Settings → Pages → Source: **GitHub Actions**. با هر push روی `main` خودش بیلد و منتشر می‌شود. آدرس: `https://USERNAME.github.io/krayechi/`

**Cloudflare Pages / Netlify** (آپلود مستقیم): `npm run build` و آپلود پوشه `dist` (آدرس ریشه، بدون `BASE_PATH`).

برای ساب‌پث دلخواه: `BASE_PATH=/name/ npm run build`

## تنظیمات قبل از فروش
- `src/utils/subscription.ts`: پین ادمین (`DEFAULT_ADMIN_PIN`) و آیدی تلگرام پشتیبانی را تغییر بده.
- قفل اشتراک سمت مرورگر است و امنیت واقعی ندارد؛ برای فروش جدی نیاز به اعتبارسنجی سمت سرور است.
